# 方圆玩法闭环 清单

## 目标

将当前半成品的 `fangyuan` 推进为可用的 v0 玩法闭环：玩家可以从大厅进入方圆家园，加载首包 Palette 和 Layout，选择固定 Prefab，完成放置、选中、移动、旋转、删除，获得对象数量和预算反馈，保存本地布局，并在再次进入时恢复结果。

v0 不覆盖远端 MyServer 同步、完整多人 authority 回放、资源热更新、Bake、LOD、复杂预算审核、复杂资产生产管线和完整 UI Gallery 化。

## 基础原则

- [ ] 每个阶段只推进一个可独立验证的玩法链路节点。
- [ ] 优先复用 `project/src/framework/fangyuan/`、`project/src/framework/scene/`、`project/src/framework/ui/` 和 `project/src/game/scenes/` 的既有边界。
- [ ] 暂停新增大规模底层抽象，除非它直接服务 v0 闭环。
- [ ] 每个实现阶段完成后至少运行 `cargo fmt` 和 `cargo check`。
- [ ] 涉及 UI 或交互的阶段，使用至少一个手机窗口 profile 做手动验收。
- [ ] 阶段完成后记录开发总结和验证记录，再进入下一阶段。
