# 方圆灵构技术文档

这个目录记录方圆灵构从世界观概念落到工程实现时需要遵守的规范、架构和阶段记录。

方圆灵构不是单一渲染功能，也不是单一玩法系统。它会同时影响家园、装备、技能、NPC、天道自演、对象资源构建、蓝图审核、运行时渲染、LOD、Bake 和资源加载。

世界观概念仍以 [世界观/方圆灵构](../世界观/方圆灵构.md) 为准。生成、审核、运行时和资源管线的现行文档集中在本目录。

## 推荐阅读路径

- 生成或修改静态蓝图：依次阅读 [生成流程与权限边界](./规范/生成流程与权限边界.md)、[蓝图格式与生成约束](./规范/蓝图格式与生成约束.md) 和 [审核与预算规则](./规范/审核与预算规则.md)。
- 开发动态表现或技能视觉：阅读 [动态表现与技能规则](./规范/动态表现与技能规则.md)，再结合运行时架构。
- 开发 runtime primitive、渲染、LOD 或同步：阅读 [运行时与渲染架构](./架构/运行时与渲染架构.md)。
- 规划 AI 自动生成方圆结构并接入颜色、法线和噪点图集渲染：阅读 [AI 生成与图集材质渲染](./架构/AI生成与图集材质渲染.md)，再据此拆分开发 checklist。
- 开发 Prefab、Scene Layout、Chunk、Bake 或加载：阅读 [资源构建与加载](./架构/资源构建与加载.md)。
- 查询阶段记录和后续事项：阅读 [路线图](./路线图.md) 和 [已归档 checklists](./checklists/)。

## 文档职责

- `规范/`：定义生成、数据格式、审核预算以及动态表现必须遵守的约束。
- `架构/`：说明运行时、渲染、资源构建和加载如何承载这些规范。
- `路线图.md`：保留阶段开发记录、风险和后续事项，不作为当前实现状态的唯一依据。
- `checklists/`：保留各阶段已经归档的任务、验证和历史行号证据。

旧文件路径保留兼容导航页。现行文档不得继续把规则写回兼容页，也不得用历史 checklist 的行号判断当前规则。
