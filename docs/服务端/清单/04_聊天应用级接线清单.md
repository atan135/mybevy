# 聊天应用级接线 清单

## 目标

将现有 MyServer 聊天 WSS runtime 接入 Bevy 应用生命周期，使客户端能够从 auth 响应保存 `services.chat`、使用当前 character-bound ticket 完成鉴权、稳定处理 request/response 和异步 push，并把邮件通知转交邮件客户端。

首要交付是应用级连接、鉴权、生命周期和 typed event，不默认承诺可见聊天窗口；可见聊天窗口是否纳入首版需在阶段 1 明确。

## 依赖与边界

- 依赖现有 `project/src/game/myserver/chat.rs` 的 WSS endpoint、packet codec、router 和 worker。
- 依赖 MyServer auth 登录、选角和补票响应下发公网 `services.chat` descriptor。
- 邮件通知消费依赖 `05_邮箱界面与通知闭环清单.md`。
- 生产客户端只使用 Caddy WSS 公网入口，不读取 registry 或直连 chat-server 内部 listener。
- Android 真机 WSS、网络切换与前后台验收集中转移至 `07_公网部署后Android真机验收清单.md`，必须在 chat 公网入口部署后执行。

- [x] 区分 WebSocket transport connected、chat authenticating 和业务 ready，不把握手成功当作鉴权成功。（验证：ChatAuth 状态机单测与 local WS `ChatAuthRes(ok=true)` 实测）
