# 战斗与交战同步设计

## 文档定位

本文记录大世界战斗、自动交战上下文和不同同步域的设计边界。

本文是玩法与技术设计文档，不代表完整战斗结算、职业技能库、服务端大规模战斗或正式回放服务已经实现。具体协议、房间策略和性能参数进入开发阶段后再单独固化。

## 核心原则

玩家不需要确认“进入战斗”。战斗应当是玩家在世界中执行有效行为后，系统自动建立的交战关系。

战斗域是服务器内部的同步单位，不是玩家需要点击进入的玩法入口。玩家仍然在大世界中移动、观察和行动；只有能够彼此产生战斗影响的实体，才会被纳入对应的交战上下文。

## 自动交战上下文

### 建立条件

首次产生有效战斗影响时自动建立上下文，例如：

- 玩家对怪物造成伤害。
- 玩家受到攻击、控制或其他战斗效果。
- 玩家对战斗实体施加治疗、护盾、强化或驱散。
- 技能的真实范围或持续区域覆盖了其他战斗实体。

玩家不需要发起组队确认，也不需要接受战斗邀请。安全区、和平区域和 PvP 规则仍然可以禁止某类攻击，但这是区域规则，不是战斗加入确认。

### 成员边界

以下实体通常进入交战上下文：

- 能改变战斗结果的玩家。
- 被攻击、保护、控制或治疗的玩家与怪物。
- 其行为会直接影响命中、碰撞、状态或结算的召唤物和交互物。

以下对象不进入交战上下文：

- 只是路过或观看的玩家。
- 观界和因果回放的只读投影。
- 不参与规则判定的装饰、特效和方圆 primitive。
- 只接收战斗结果展示、不改变结果的远端观察者。

### 生命周期

交战上下文在仍有未完成的技能、状态、仇恨或伤害关系时保持活跃。所有直接战斗影响消失并经过短暂退出窗口后，上下文自动结束。玩家不需要手动离开。

## 同步域

同一世界可以同时存在多种同步方式：

| 同步域 | 适用内容 | 参与方式 |
| --- | --- | --- |
| 世界状态域 | 普通移动、NPC、探索、生活和场景状态 | 服务器状态同步、快照和 AOI |
| 小规模交战域 | 少量实体之间的高频战斗关系 | 有限参与者帧同步 |
| 大规模战斗域 | 大范围战争、群体技能和高密度战斗 | authority 固定 Tick 结算并下发权威事件 |
| 活动事件域 | 宗门建设、法会、投票、展示和非战斗活动 | 事件同步或状态同步 |
| 观界域 | 实时观察和因果回放 | 只读快照、事件流或回放重建 |

同步模式是服务器内部实现细节，不应变成玩家需要理解或选择的 UI 状态。

## 规模超限处理

帧同步只覆盖有限的直接交战关系。参与者数量、技能频率或实体依赖超过当前预算时，系统自动执行以下策略之一：

- 将交战上下文切换为 authority 固定 Tick 结算。
- 按区域、目标或战线拆分为多个上下文。
- 降低非关键视觉和远端状态更新频率。
- 通过天道灵压、镜像和分流入口降低新增直接交战关系。

切换时先保存权威检查点，再发送模式转换事件，客户端从检查点继续展示。不能因为同步预算不足而要求玩家确认或强制退出战斗。

## 技能规则与灵构表现

技能由三层组成：

```text
系统技能模板 + 角色成长修正 + 玩家灵构视觉蓝图
```

系统技能模板决定：

- 伤害、治疗和控制系数。
- 真实范围、方向和目标规则。
- 前摇、命中、持续和后摇。
- 冷却、消耗、打断和叠加规则。

角色成长只通过服务端认可的属性、职业、装备和技能进度修正结果。玩家或 AI 生成的视觉蓝图只能改变方相/圆相组合、颜色、材质、节奏、拖尾和命中反馈。

危险边界、命中时刻、敌我识别和必要的方向标记属于强制可读层，不能被视觉蓝图隐藏、缩小或伪装。

## 战斗事件与回放

战斗客户端不需要同步每一个视觉 primitive。权威层只记录必要的输入、规则结果和语义事件，例如：

- 技能开始、命中和结束。
- 伤害、治疗、控制和状态变化。
- 目标、方向、起始 tick、技能模板、蓝图版本和随机种子。
- 交战上下文建立、切换和结束。

客户端根据这些事件播放经过审核的视觉蓝图。因果回放使用权威检查点、事件日志、规则版本和蓝图版本重建；回放过程不生成真实实体，也不会改变当前世界。

## 第一阶段建议边界

首个可验证版本建议覆盖：

- 一个大世界区域和自动触发的 PvE 交战。
- 一个小规模交战同步实现。
- 超过预算后自动切换为 authority 事件结算的离线 fixture。
- 投射物、范围技能和护盾三个固定技能模板。
- 每个模板支持受限视觉蓝图。
- 一段战斗事件的观界回放。

参与者上限、同步 Tick、切换阈值、战斗脱离窗口和具体数值均属于待定配置，不在本文提前锁死。

## 风险边界

- 不能把视觉 primitive 作为战斗规则实体。
- 不能让 AI 或玩家蓝图决定伤害、收益或真实命中范围。
- 不能把旁观者强行加入帧同步。
- 不能用天道灵压掩盖未定义的服务端容量问题。
- 不能让同步模式切换产生角色资产、战斗结果或回放内容差异。
