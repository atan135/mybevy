# AI Login Reference Assets

The `ai_login_background.png`, `ai_login_sigil.png`, and `ai_login_panel_surface.png` assets were derived from the workspace-provided reference image `artifacts/raw_image/ui/login_design.png` for the AI login reference prototype.

The panel surface preserves the original right-side technical ornament while replacing its baked labels and separators. The runtime owns all visible labels and button states; no source text or watermark is used as a UI control.
